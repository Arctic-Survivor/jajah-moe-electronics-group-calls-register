# سجل مكالمات البدالة

نظام تسجيل مكالمات البدالة (التحويلة 0) — مجموعة الهندسة الإلكترونية، إدارة المنشآت التعليمية، وزارة التربية والتعليم، مملكة البحرين.

ملف واحد (`main.ts`) فيه السيرفر والواجهة معاً — بدون أي حزم خارجية وبدون خطوة بناء (build). قاعدة البيانات Deno KV (مفعّلة تلقائياً على Deno Deploy).

## المحتويات

| الملف | الوصف |
|---|---|
| `main.ts` | الكود كامل: سيرفر + واجهة (المُشغَّل الفعلي) |
| `deno.json` | إعدادات المشروع وأوامر التشغيل |
| `.gitignore` | استبعاد ملفات قاعدة البيانات المحلية من GitHub |
| `موظفي-المجموعة.csv` | قائمة الحسابات الجاهزة للاستيراد بعد أول تشغيل |

## التشغيل محلياً (اختياري، للتجربة قبل الرفع)

يتطلب [Deno](https://deno.com) مثبّت على جهازك:

```bash
deno task start
```

هيفتح على `http://localhost:8000`.

## الرفع على GitHub

```bash
cd deno-switchboard
git init
git add .
git commit -m "سجل مكالمات البدالة"
git branch -M main
git remote add origin https://github.com/<اسم-المستخدم>/<اسم-المستودع>.git
git push -u origin main
```

(لو مفيش عندك مستودع لسه: أنشئي واحد جديد **فاضي** من GitHub — بدون README أو .gitignore تلقائي — وانسخي رابطه بدل `<اسم-المستخدم>/<اسم-المستودع>`.)

## ربط المستودع بـ Deno Deploy

1. افتحي https://dash.deno.com وسجّلي دخول (بحساب GitHub نفسه أسهل).
2. **New Project** → **Import from GitHub** → اختاري المستودع اللي رفعتيه.
3. **Entry Point**: `main.ts`
4. **Branch**: `main`
5. Deploy.

كده أي `git push` جديد على `main` هيعمل نشر تلقائي (Continuous Deployment) — من غير ما تحتاجي تعيدي رفع أي حاجة يدوياً بعد كده.

Deno KV بيتفعّل تلقائياً لكل مشروع، مفيش إعداد إضافي مطلوب.

بعد أول نشر هتحصلي على رابط شبه `https://اسم-مشروعك.deno.dev` — ده الرابط اللي يتوزّع على الموظفات.

## أول استخدام بعد الرفع

1. افتحي الرابط — هتظهر شاشة "إنشاء تنظيم جديد" (مفيش أي حساب لسه).
2. اعملي حساب المشرف بنفسك (اسمك + رقمك الشخصي + كلمة مرور تختاريها).
3. من تبويب "الحسابات" استوردي `موظفي-المجموعة.csv`.
4. من تبويب "قوائم التحويل" ضيفي جهات التحويل.
5. ابعتي **رابط الموقع نفسه** (`https://اسم-مشروعك.deno.dev`) لكل موظفة، وقوليلها رقمها الشخصي وكلمة مرورها من الملف بشكل خاص — **متبعتيش الملف نفسه لأي حد**، فيه كل كلمات المرور مع بعض.

من هنا أي تغيير (تفعيل حساب، رقم تحويل جديد، إعادة تعيين كلمة مرور) بيظهر فوراً عند الكل — بلا تصدير أو استيراد.

## تحديثات لاحقة على الكود

أي تعديل تطلبيه بعد كده، هرفعلك نسخة `main.ts` جديدة — تستبدلي بيها الملف القديم في نفس المستودع وتعملي:

```bash
git add main.ts
git commit -m "تحديث"
git push
```

وهيتنشر تلقائياً خلال ثوانٍ.

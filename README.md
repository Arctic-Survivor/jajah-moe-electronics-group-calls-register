# منظومة متابعة جاهزية المدارس — وزارة التربية والتعليم (مملكة البحرين)

نظام كامل لمتابعة استمارة بدء العام الدراسي عبر القطاعات والإدارات، مع ثلاث صلاحيات:
الإدارة (الجهة)، منسق القطاع، ومدير عام شؤون المدارس.

## المزايا الرئيسية
- تمييز كامل للسنة الدراسية مع **أرشيف حقيقي**: كل سنة بياناتها مستقلة (الإدخالات، الملاحظات، التقارير).
  السنة الحالية **والسنة القادمة مباشرة** قابلتان للتعديل والتشغيل (تحضير مسبق لسنة واحدة).
  السنوات المنتهية للاطلاع والطباعة فقط (أرشيف). السنوات الأبعد مستقبلاً غير متاحة حتى يحين موعدها.
- ملاحظات إشرافية **متشعّبة**: ردود الإدارة/القطاع تظهر متداخلة تحت ملاحظة المدير لتفادي اللخبطة.
- إشعارات لكل الأدوار (الإدارة، القطاع، **والمدير العام**) مع إشعار خاص عند الرد على ملاحظة.
- **تحكّم المدير في فتح السنوات المستقبلية:** السنة القادمة تبقى مقفلة للقطاعات والإدارات حتى يفتحها مدير عام شؤون المدارس يدوياً من شريط السنوات (المدير يحضّرها مسبقاً). ٢٠٢٥-٢٠٢٦ مستثناة من احتساب التأخير.
- **التحليل حسب المحور:** تقارير وشاشات تُظهر إنجاز كل محور عبر الإدارات والقطاعات، مع إبراز المحاور المتعثرة والإدارات المعطّلة للتقدم وما لم يُنجز — لكل السنوات.
- **نقل مؤشر كامل بين الإدارات** (حصري للمدير العام): ينتقل ببياناته كاملة، يبقى في المصدر معلّماً «منقول»، ويعمل عبر القطاعات وفي أي سنة.
- خط زمني لآخر التحديثات على مستوى القطاع والوزارة.
- تقارير رسمية (HTML/PDF) تحمل السنة الدراسية بوضوح، مع وسم "(أرشيف)" للسنوات المنتهية.
- رفع تقارير القطاع للاعتماد، قفل بعد الاعتماد، وتصريح المدير بإعادة الفتح.

## النشر على Deno Deploy
1. ارفع ملفات هذه الحزمة (main.ts, data.js, index.html, deno.json) إلى جذر مستودع GitHub.
2. من Deno Deploy: اربط المستودع، ثم اربط قاعدة KV من تبويب Databases.
3. أعد النشر. بعد كل تحديث، اطلب من المستخدمين Ctrl+Shift+R لتحديث الذاكرة المؤقتة.

## ملاحظة أمنية
النسخة المحلية (النظام_المحلي_الكامل.html) تحتوي رموز الدخول بنص صريح للعرض فقط —
لا تُرفع على الإنترنت. نسخة الإنتاج تستخدم رموزاً مُجزّأة (SHA-256).
